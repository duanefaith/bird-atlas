# 鸟讯地图：普通 / 卫星底图

状态：方案已确认，供审阅。本文只定行为，不含实现。

## 目标

鸟讯地图可以在「普通」和「卫星」之间切换。默认普通。选择记在本机；存不了也不报错。

官方路径的卫星使用高德自己的影像和路网地名。回退路径仍只画高德数据：影像使用高德卫星瓦片；道路地名使用下面写明的高德注记层，并在实现时按验收复验。复验若发现注记把影像盖成整张普通图，回退卫星就只留影像。

鸟点、筛选、定位、导航用的坐标不改。

## 做法

优先用现有高德 JS API 2.0，不新加地图 SDK，不新申请密钥。

- 切换控件用官方 `AMap.MapType`。官方控件能完成切换时，不另做一套按钮。
- 普通是现在的默认矢量底图。
- 卫星是官方 `AMap.TileLayer.Satellite` 加 `AMap.TileLayer.RoadNet`。打开路网地名。不打开路况，视图保持 2D。
- 若 `MapType` 内部已经使用这两类图层，就不要再手工叠一套重复图层。
- 控件自己不记住刷新前的选择。创建时按本机保存的值设置初始类型。高德 JS API 2.0 里普通的 `defaultType` 为 0，卫星为 1。若运行中的版本取值不同，存储里仍然只写 `normal` / `satellite`，并用该版本的官方取值让控件高亮和画面一致。

`MapType` 放在地图左上，避开现有右上角缩放工具条，也不盖住左下 logo 和右下署名。宽度小于 700px、地图高 300px 时，控件仍能点到，且不挡住工具条、logo、署名。位置用控件自带参数调整。主路径不因为摆放问题改成自制按钮。

换底图时保留圆点和 ◆ 点位。官方控件创建失败，或整次高德 JS 加载失败时，整页进入下面的 Leaflet 回退，不停留在一张没有切换的高德地图上。高德地图已经显示之后，只有卫星切换失败时，留在高德地图并回到普通，不因此改走 Leaflet。

## Leaflet 回退

Leaflet 1.9.4 只是现有回退渲染器。回退底图只使用高德瓦片。

- 普通：保持现在的 `https://webrd0{s}.is.autonavi.com/appmaptile?lang=zh_cn&size=1&scale=1&style=8&x={x}&y={y}&z={z}`，子域 `1234`，最大 18 级。
- 卫星影像：`https://webst0{s}.is.autonavi.com/appmaptile?style=6&x={x}&y={y}&z={z}`，同样的子域和最大级别。
- 道路地名：把 `https://webst0{s}.is.autonavi.com/appmaptile?style=8&x={x}&y={y}&z={z}` 叠在影像上面。
- 禁止把普通图那条 `webrd … style=8` 叠到影像上。

设计阶段抽查了人民广场附近 z=14、子域 1 的一瓦：`webst style=6` 是 JPEG 影像；`webst style=8` 是 RGBA（约 45% 全透明、26% 半透明、28% 不透明），合成后道路和地名在上，街区和绿地仍能看见影像；`webrd style=8` 是索引色整张普通图，没有可用透明通道。实现时再目视复验一处鸟点（滩涂或公园）和另一个缩放级别，确认影像没有被涂死。复验不通过就去掉注记层，卫星只留 `style=6`，开关仍显示卫星。不用别家的地名层补上。

这些 `webst` 地址和现用路网一样，不属于公开文档里的正式瓦片接口，可能改地址或停止服务，也没有配额合同。这是回退路径的维护风险。官方路径不依赖这些地址。

回退地图没有高德 `MapType`，所以只在这张地图上放一个「普通 / 卫星」文字开关，放在右上，避开 Leaflet 左上缩放和署名。主路径不显示这个开关。署名保留一处「© 高德地图」。子域 `1` 到 `4` 在同一次抽查里都能返回上述影像和注记。

## 记住选择

键名 `birdnews-basemap`。只认 `normal` 和 `satellite`。缺省、空值、其他文字、读取失败都当作 `normal`。两条引擎读写同一个键。

用户成功切换后再写。读写都捕获异常：隐私模式、配额满或存储被禁用时，地图继续可用，不把异常抛到页面上。

存储可写时，画面、控件选中态、存储值三者相同。存储不可写时，当前画面和控件选中态相同即可。已经成功切到卫星、但写入失败时，保持卫星画面和控件，不把这次成功的切换撤掉。

## 失败

卫星失败只包括两类：切换或创建卫星图层时抛错；回退路径里，当前视图的影像请求都已结束且没有任何成功瓦片。刚加上图层、瓦片尚未返回时不算失败。出现这类失败时，画面和控件回到普通。存储可写则写成 `normal`，避免下次刷新再次进入失败的卫星；用户可以再点一次。存储可写时，一次影像失败会让下一次官方路径也从普通开始。

不算失败、也不改当前模式的情况：官方路径里单块瓦片暂时缺失；回退路径里已经有成功影像瓦片之后的个别失败；注记层失败。注记失败时保持卫星影像。官方 JS 没有可靠的整屏瓦片失败回调时，不用灰块猜测失败，画面和控件都保持卫星。高德地图本身可用、只是卫星切换失败时，留在高德地图，不改走 Leaflet。

## 保持不变

- 点位仍只用 `glat` / `glng`（GCJ-02）。导航仍是高德 URI，`coordinate=gaode`。
- 筛选、点标记高亮卡片、点卡片定位、◆ 帖子点位和颜色不改。
- 图鉴页和 `label.html` 不改。
- 不遮挡、不隐藏高德 logo 和 copyright，也不再降低现有 logo 透明度。

## 改动落在生成源

`README.md` 写明 `news/` 由 birdnews 单独生成，图鉴构建不改它。本仓库没有生成器。`news/data/news.json` 的 `source_digest` 指向不在本仓库的 digest 文件。

实现时修改父机 `/workspace/birdnews` 中产出 `news/assets/news.js` 的源。回退开关的位置写在生成 `news.css` 的源里，只加这个开关的规则。然后走原来的鸟讯发布。只改本仓库里已经生成的 `news/index.html`、`news/assets/news.js` 或 `news/assets/news.css`，下次发布会被覆盖，不能算做完。

## 验收

1. 高德路径能在普通和卫星之间切换。卫星能看见影像、道路和地名。logo 和署名仍在，鸟点仍在。
2. 强制走 Leaflet 时，两种都能切换，请求的底图只有高德。普通图没有盖住影像。注记复验不通过时，卫星只有影像，开关显示卫星。
3. 选卫星后刷新，控件高亮和画面都是卫星，官方路径同时有路网。选普通后刷新回到普通。非法存储值打开时是普通。
4. `localStorage` 读写抛错时，没有未捕获异常，地图可用，画面和控件一致。
5. 官方路径在卫星切换抛错时回到普通。回退路径在当前视图影像请求全部结束且没有成功瓦片时回到普通。控件和可写存储都是普通，鸟点还在。单块瓦片失败不切换。
6. 宽度小于 700px 时，切换可点，不挡缩放、工具条、logo、署名。
7. 点位点击、卡片定位、导航链接、筛选后的地图缩放与改动前一致。
8. 用生成源重新产出鸟讯后，上述行为仍在。

## 不做

地形；天地图、OSM、Esri、百度或其他底图；新的地图 SDK；新密钥；主路径上的自制切换条；把 `webrd style=8` 整张普通图叠到影像上。
